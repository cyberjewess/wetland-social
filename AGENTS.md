Coding Loop:
1. Plan loop
    a. Prompt from developer
    b. Make plan
    c. Confirm or refine
    d. Once confirmed, make a TODO document
2. Development loop
    a. Make a new branch
    b. Do tasks
    c. When more than 4 files changed, make a commit with message less than 200 chars
    d. When done core work
        i. write tests
        ii. update documentation
