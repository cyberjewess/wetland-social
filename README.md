# wetland-social

**wetland-social** is a stratified social media app built on top of atproto. Every post is published at a specific level. There are 4 levels: circle, radius, bioregion, global.

## Levels
### Circle
A circle is a trusted group of friends / followers. A user can have up to 5 circles. We recommend one of those circles is open to all followers. Circles can be modified at any time.

### Radius
Your radius is an adjustable geofence around a chosen physical location. This can be modified only once per day.

### Bioregion
Bioregions are the natural ecosystem regions of the world. [Explore them at oneearth.org](https://www.oneearth.org/navigator/). This can be modified only once per day.

### Global 
The global level is similar to existing social media. Anyone anywhere can see your post.
